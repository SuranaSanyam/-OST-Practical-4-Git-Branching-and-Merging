**Performing Git Branching and Merging**

Git branching and merging are essential features that help developers manage code efficiently while working on software projects. A branch is an independent line of
development that allows developers to work on new features, fix bugs, or test changes without affecting the main project. Typically, developers create a new branch
using the `git branch` or `git checkout -b` command, make their changes, and commit them separately. Once the work is completed and tested, the branch is merged back
into the main branch using the `git merge` command. If two branches modify the same part of a file, Git may generate a merge conflict, which must be resolved
manually before completing the merge. This workflow enables multiple developers to collaborate on the same project simultaneously without overwriting each other's
work. Git branching and merging improve project organization, support parallel development, simplify collaboration, and maintain a stable main branch while allowing
continuous development of new features.
